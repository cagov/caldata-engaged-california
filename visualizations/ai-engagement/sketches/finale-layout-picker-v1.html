Finale layout picker

Generates Phase 2 (27 ideas) layouts with the same engine as the sketches — new seed, new layout. Keep the ones you like; download one as whirl-finale-layout.js and drop it next to the sketches and they will use it instead of computing their own.

Kept layouts

How a kept layout reaches the sketches. "Download" on a card writes whirl-finale-layout.js, which sets window.WHIRL_FINALE_LAYOUTS keyed by field ("2340x1140", "1400x820"). Save it into sketches/. Both sketches load that file if present and, when the field, labels, line breaks and font sizes all match, draw those exact positions instead of running their own selection; otherwise they fall back to computing. One layout per field lives in the file — downloading from a card replaces that field's entry and keeps the other field's entry from the file currently loaded (if any). Kept layouts also persist in this browser's localStorage. Positions come from this engine in this browser, so what you see here is what the sketches will draw.
